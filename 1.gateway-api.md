# 🧩 Problem Statement (Migrate from Ingress to Gateway API)

<details>
<summary>Click to expand the problem statement</summary>

A Kubernetes cluster has an existing web application exposed via an Ingress resource with HTTPS. Your task is to migrate this application to use the Gateway API while maintaining HTTPS access.

Your task is to:

1. Connect to the **correct host**
2. Create a **Gateway** reusing the existing TLS and listener config from the Ingress
3. Create an **HTTPRoute** reusing the existing routing rules from the Ingress
4. Test the new Gateway API configuration
5. Delete the old Ingress resource

```
[candidate@base]$ ssh <hostname>
```


### 📋 Configure the following:

1. A GatewayClass named **`nginx`** is already installed in the cluster. Create a Gateway named **`app-gateway`** with the following specifications:
   * **Hostname:** `gateway.app.k8s.local`
   * Maintain the existing TLS and listener configurations from the Ingress resource named **`frontend`**

2. Create an HTTPRoute named **`app-route`** with the following specifications:
   * **Hostname:** `gateway.app.k8s.local`
   * Maintain the existing routing rules from the Ingress resource named **`frontend`**

3. Delete the existing Ingress resource named **`frontend`**

4. Test the Gateway API configuration using:

```bash
curl -Lk https://gateway.app.k8s.local:32000
```

# 🛠 Setup Practice Scenario

<details>
<summary>Click to expand setup steps</summary>

| Script | Purpose |
|--------|---------|
| `setup_q01_gateway.sh` | Installs NGINX Ingress Controller and NGINX Gateway Fabric, creates namespace, app, TLS secret, Ingress and DNS entry — run before practice (re-run anytime) |

---

### 📥 Script : setup_q01_gateway.sh

```bash
#!/bin/bash
# ============================================================
# CKA Practice | q01: Migrate from Ingress to Gateway API
# setup_q01_gateway.sh
# Installs NGINX Ingress Controller and NGINX Gateway Fabric,
# deploys web app, creates TLS secret and existing Ingress
# Re-run safe: only resets candidate work on subsequent runs
# Run on: controlplane node
# ============================================================

set -euo pipefail

NAMESPACE="production"
HOSTNAME="gateway.app.k8s.local"
TLS_SECRET="app-ingress-tls"
TLS_DIR="$HOME/tls-gateway"
INGRESS_NAME="frontend"

echo ""
echo "==========================================="
echo " CKA q01 — Setting up Gateway API scenario..."
echo "==========================================="
echo ""

# ── Step 1: Reset only candidate work ────────────────────────
echo "[1/9] Resetting candidate work from previous attempt..."

# Delete candidate-created resources
# Use 2>/dev/null || true to handle case where CRDs don't exist yet (first run)
kubectl delete gateway app-gateway -n "$NAMESPACE" \
    --ignore-not-found 2>/dev/null || true
kubectl delete httproute app-route -n "$NAMESPACE" \
    --ignore-not-found 2>/dev/null || true
kubectl delete ingress "$INGRESS_NAME" -n "$NAMESPACE" \
    --ignore-not-found 2>/dev/null || true

# Delete candidate-created YAML files
rm -f "$HOME/app-gateway.yaml"
rm -f "$HOME/app-route.yaml"

echo "  Candidate work cleared."

# ── Step 2: Verify Helm is installed ─────────────────────────
echo "[2/9] Verifying Helm is installed..."
if ! command -v helm &>/dev/null; then
    echo "  Helm not found — installing..."
    curl -fsSL https://raw.githubusercontent.com/helm/helm/main/scripts/get-helm-3 | bash
    echo "  Helm installed."
else
    echo "  Helm already installed: $(helm version --short)"
fi

# ── Step 3: Install Gateway API CRDs if not present ──────────
echo "[3/9] Checking Gateway API CRDs..."
if kubectl get crd gateways.gateway.networking.k8s.io &>/dev/null; then
    echo "  Gateway API CRDs already installed — skipping."
else
    echo "  Installing Gateway API CRDs..."
    kubectl apply -f https://github.com/kubernetes-sigs/gateway-api/releases/download/v1.2.0/standard-install.yaml
    echo "  Gateway API CRDs installed."
fi

# ── Step 4: Install NGINX Ingress Controller if not present ──
echo "[4/9] Checking NGINX Ingress Controller..."
if kubectl get deployment ingress-nginx-controller -n ingress-nginx &>/dev/null; then
    echo "  NGINX Ingress Controller already running — skipping."
else
    echo "  Installing NGINX Ingress Controller..."
    kubectl apply -f https://raw.githubusercontent.com/kubernetes/ingress-nginx/controller-v1.11.0/deploy/static/provider/cloud/deploy.yaml

    # Patch to NodePort
    kubectl patch svc ingress-nginx-controller \
        -n ingress-nginx \
        -p '{"spec": {"type": "NodePort"}}'

    # Fix HTTPS NodePort to 31443
    kubectl patch svc ingress-nginx-controller \
        -n ingress-nginx \
        --type=json \
        -p='[{"op":"replace","path":"/spec/ports/1/nodePort","value":31443}]'

    echo "  Waiting for NGINX Ingress Controller to be Ready..."
    kubectl wait --for=condition=ready pod \
        -l app.kubernetes.io/component=controller \
        -n ingress-nginx --timeout=180s
    echo "  NGINX Ingress Controller installed — HTTPS NodePort: 31443"
fi

# ── Step 5: Install NGINX Gateway Fabric if not present ──────
echo "[5/9] Checking NGINX Gateway Fabric..."
if helm status ngf -n nginx-gateway &>/dev/null; then
    echo "  NGINX Gateway Fabric already installed — skipping."
else
    echo "  Installing NGINX Gateway Fabric..."

    # --server-side required due to large CRD annotation size
    kubectl apply -f https://raw.githubusercontent.com/nginx/nginx-gateway-fabric/v2.5.1/deploy/crds.yaml \
        --server-side

    helm install ngf oci://ghcr.io/nginx/charts/nginx-gateway-fabric \
        --create-namespace \
        -n nginx-gateway \
        --version 2.5.1 \
        --set-json 'nginx.service.nodePorts=[{"port":32080,"listenerPort":80},{"port":32000,"listenerPort":443}]'

    echo "  Waiting for NGINX Gateway Fabric to be Ready..."
    kubectl wait --for=condition=ready pod \
        -l app.kubernetes.io/name=nginx-gateway-fabric \
        -n nginx-gateway --timeout=180s
    echo "  NGINX Gateway Fabric installed — HTTPS NodePort: 32000"
fi

# ── Step 6: Add /etc/hosts entry if not present ──────────────
echo "[6/9] Checking /etc/hosts entry..."
if grep -q "$HOSTNAME" /etc/hosts; then
    echo "  /etc/hosts entry already exists — skipping."
else
    NODE_IP=$(kubectl get nodes \
        --selector='node-role.kubernetes.io/control-plane' \
        -o jsonpath='{.items[0].status.addresses[?(@.type=="InternalIP")].address}')
    echo "$NODE_IP $HOSTNAME" | sudo tee -a /etc/hosts > /dev/null
    echo "  Added: $NODE_IP $HOSTNAME"
fi

# ── Step 7: Create namespace and app if not present ──────────
echo "[7/9] Checking namespace and app..."
if kubectl get deployment web-app -n "$NAMESPACE" &>/dev/null; then
    echo "  Namespace and app already exist — skipping."
else
    echo "  Creating namespace and deploying app..."
    kubectl apply -f - <<EOF
apiVersion: v1
kind: Namespace
metadata:
  name: $NAMESPACE
---
apiVersion: v1
kind: ConfigMap
metadata:
  name: web-app-content
  namespace: $NAMESPACE
data:
  index.html: |
    Hello! web-server is running ✅

---
apiVersion: apps/v1
kind: Deployment
metadata:
  name: web-app
  namespace: $NAMESPACE
spec:
  replicas: 1
  selector:
    matchLabels:
      app: web-app
  template:
    metadata:
      labels:
        app: web-app
    spec:
      containers:
      - name: nginx
        image: nginx:1.27
        ports:
        - containerPort: 80
        volumeMounts:
        - name: web-content
          mountPath: /usr/share/nginx/html
      volumes:
      - name: web-content
        configMap:
          name: web-app-content
---
apiVersion: v1
kind: Service
metadata:
  name: web-service
  namespace: $NAMESPACE
spec:
  selector:
    app: web-app
  ports:
  - name: http
    port: 80
    targetPort: 80
EOF

    kubectl wait --for=condition=available deployment/web-app \
        -n "$NAMESPACE" --timeout=120s
    echo "  web-app is Ready."
fi

# ── Step 8: Create TLS secret if not present ─────────────────
echo "[8/9] Checking TLS secret..."
if kubectl get secret "$TLS_SECRET" -n "$NAMESPACE" &>/dev/null; then
    echo "  TLS secret already exists — skipping."
else
    echo "  Creating TLS secret..."
    mkdir -p "$TLS_DIR"
    openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
        -keyout "$TLS_DIR/app.key" \
        -out "$TLS_DIR/app.crt" \
        -subj "/CN=$HOSTNAME" 2>/dev/null

    kubectl create secret tls "$TLS_SECRET" \
        --cert="$TLS_DIR/app.crt" \
        --key="$TLS_DIR/app.key" \
        -n "$NAMESPACE"
    echo "  TLS secret created."
fi

# ── Step 9: Recreate Ingress resource ────────────────────────
echo "[9/9] Creating Ingress resource '$INGRESS_NAME'..."

kubectl apply -f - <<EOF
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: $INGRESS_NAME
  namespace: $NAMESPACE
  annotations:
    nginx.ingress.kubernetes.io/force-ssl-redirect: "true"
spec:
  ingressClassName: nginx
  tls:
  - hosts:
    - $HOSTNAME
    secretName: $TLS_SECRET
  rules:
  - host: $HOSTNAME
    http:
      paths:
      - path: /
        pathType: Prefix
        backend:
          service:
            name: web-service
            port:
              number: 80
EOF

echo "  Ingress '$INGRESS_NAME' created."

echo ""
kubectl get ingressclass
echo ""
kubectl get gatewayclass
echo ""
kubectl get ingress "$INGRESS_NAME" -n "$NAMESPACE"
echo ""
echo "✅ Practice scenario is ready!"
echo ""
echo "   Ingress is live — verify:"
echo "   curl -Lk https://gateway.app.k8s.local:31443"
echo ""
echo "   GatewayClass 'nginx' is ready for migration."
echo "   After migration test using:"
echo "   curl -Lk https://gateway.app.k8s.local:32000"
echo ""
echo "   💪 Go create the Gateway and HTTPRoute!"
echo ""
```

# ✅ Solution

<details>
<summary>Click to expand the solution</summary>

### Step 1: Inspect the existing Ingress resource

```bash
kubectl describe ingress frontend -n production
```

Note down:
- **Hostname:** `gateway.app.k8s.local`
- **TLS Secret:** `app-ingress-tls`
- **Backend Service:** `web-service:80`
- **Path:** `/`

---

### Step 2: Verify GatewayClass is available

```bash
kubectl get gatewayclass
```

Expected output:

```
NAME    CONTROLLER                                   ACCEPTED
nginx   gateway.nginx.org/nginx-gateway-controller   True
```

---

### Step 3: Create the Gateway manifest

```bash
vim app-gateway.yaml
```

```yaml
apiVersion: gateway.networking.k8s.io/v1
kind: Gateway
metadata:
  name: app-gateway
  namespace: production
spec:
  gatewayClassName: nginx
  listeners:
  - name: https
    hostname: gateway.app.k8s.local
    port: 443
    protocol: HTTPS
    tls:
      mode: Terminate
      certificateRefs:
      - kind: Secret
        name: app-ingress-tls
        namespace: production
```

```bash
kubectl apply -f app-gateway.yaml
```

---

### Step 4: Verify the Gateway is ready

```bash
kubectl get gateway app-gateway -n production
```

Expected output:

```
NAME          CLASS   ADDRESS   PROGRAMMED   AGE
app-gateway   nginx             True         15s
```

---

### Step 5: Create the HTTPRoute manifest

```bash
vim app-route.yaml
```

```yaml
apiVersion: gateway.networking.k8s.io/v1
kind: HTTPRoute
metadata:
  name: app-route
  namespace: production
spec:
  parentRefs:
  - name: app-gateway
    namespace: production
  hostnames:
  - gateway.app.k8s.local
  rules:
  - matches:
    - path:
        type: PathPrefix
        value: /
    backendRefs:
    - name: web-service
      port: 80
```

```bash
kubectl apply -f app-route.yaml
```

---

### Step 6: Verify the HTTPRoute

```bash
kubectl get httproute app-route -n production
```

Expected output:

```
NAME        HOSTNAMES                     AGE
app-route   ["gateway.app.k8s.local"]     10s
```

---

### Step 7: Delete the existing Ingress

```bash
kubectl delete ingress frontend -n production
```

Confirm deletion:

```bash
kubectl get ingress -n production
```

Expected output:

```
No resources found in production namespace.
```

---

### Step 8: Test the Gateway API configuration

```bash
curl -Lk https://gateway.app.k8s.local:32000
```

You should receive the nginx welcome page — now served via **Gateway API**. ✅

### 🧹 Script : reset_q01_gateway.sh

```bash
#!/bin/bash
# ============================================================
# CKA Practice | q01: Migrate from Ingress to Gateway API
# reset_q01_gateway.sh
# Removes all resources, controllers, CRDs,
# hosts entry, TLS files and candidate YAML files
# Run on: controlplane node
# ============================================================

set -euo pipefail

NAMESPACE="production"
HOSTNAME="gateway.app.k8s.local"
TLS_DIR="$HOME/tls-gateway"

echo ""
echo "==========================================="
echo " CKA q01 — Restoring cluster to baseline..."
echo "==========================================="
echo ""

# ── Delete namespace ──────────────────────────────────────────
echo "[1/7] Deleting namespace '$NAMESPACE'..."
kubectl delete namespace "$NAMESPACE" --ignore-not-found
echo "  Namespace and all resources removed."

# ── Uninstall NGINX Gateway Fabric ───────────────────────────
echo "[2/7] Uninstalling NGINX Gateway Fabric..."
helm uninstall ngf -n nginx-gateway 2>/dev/null || true
kubectl delete namespace nginx-gateway --ignore-not-found
echo "  NGINX Gateway Fabric removed."

# ── Remove NGINX Gateway Fabric CRDs ─────────────────────────
echo "[3/7] Removing NGINX Gateway Fabric CRDs..."
kubectl delete -f https://raw.githubusercontent.com/nginx/nginx-gateway-fabric/v2.5.1/deploy/crds.yaml \
    --ignore-not-found 2>/dev/null || true
echo "  NGINX Gateway Fabric CRDs removed."

# ── Remove Gateway API CRDs ───────────────────────────────────
echo "[4/7] Removing Gateway API CRDs..."
kubectl delete -f https://github.com/kubernetes-sigs/gateway-api/releases/download/v1.2.0/standard-install.yaml \
    --ignore-not-found 2>/dev/null || true
echo "  Gateway API CRDs removed."

# ── Remove NGINX Ingress Controller ───────────────────────────
echo "[5/7] Removing NGINX Ingress Controller..."
kubectl delete -f https://raw.githubusercontent.com/kubernetes/ingress-nginx/controller-v1.11.0/deploy/static/provider/cloud/deploy.yaml \
    --ignore-not-found 2>/dev/null || true
kubectl delete namespace ingress-nginx --ignore-not-found
echo "  NGINX Ingress Controller removed."

# ── Remove /etc/hosts entry and TLS files ────────────────────
echo "[6/7] Removing /etc/hosts entry and TLS files..."
sudo sed -i "/$HOSTNAME/d" /etc/hosts
rm -rf "$TLS_DIR"
echo "  Hosts entry and TLS files removed."

# ── Remove candidate YAML files ──────────────────────────────
echo "[7/7] Removing candidate YAML files..."
rm -f "$HOME/app-gateway.yaml"
rm -f "$HOME/app-route.yaml"
echo "  Candidate files removed."

echo ""
echo "✅ Cluster is back to baseline!"
echo "   Safe to move to next problem. 🚀"
echo ""
```
