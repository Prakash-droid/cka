# 🧩 Problem Statement (StorageClass Configuration)

<details>
<summary>Click to expand the problem statement</summary>

A Kubernetes cluster requires a new StorageClass to be configured for local path provisioning with delayed volume binding.

Your task is to:

1. Connect to the **correct host**
2. Create a **StorageClass** with the specified provisioner and binding mode
3. Mark it as the **default StorageClass** for the cluster

```
[candidate@base]$ ssh <hostname>
```

### 📋 Configure the following:

Create a StorageClass named **`local-fast-path`** with the following specifications:

* **Provisioner:** `rancher.io/local-path`
* **Volume binding mode:** `WaitForFirstConsumer`
* Set it as the **default StorageClass** for the cluster

</details>

# 🛠 Setup Practice Scenario

---

### 📥 Script : setup_q16_storageclass.sh

```bash
#!/bin/bash
# ============================================================
# CKA Practice | Q16: StorageClass Configuration
# setup_q16_storageclass.sh
# Cleans candidate work and prepares cluster for practice
# Re-run safe: only resets candidate work on subsequent runs
# Run on: controlplane node
# ============================================================

set -euo pipefail

STORAGECLASS="local-fast-path"

echo ""
echo "==========================================="
echo " CKA Q16 — Setting up StorageClass scenario..."
echo "==========================================="
echo ""

# ── Step 1: Reset candidate work ─────────────────────────────
echo "[1/2] Resetting candidate work from previous attempt..."
kubectl delete storageclass "$STORAGECLASS" --ignore-not-found
rm -f "$HOME/storageclass-local-fast-path.yaml"
echo "  Candidate work cleared."

# ── Step 2: Remove default annotation from any existing SC ───
echo "[2/2] Removing default annotation from existing StorageClasses..."

for sc in $(kubectl get storageclass -o jsonpath='{.items[*].metadata.name}' 2>/dev/null || true); do
    IS_DEFAULT=$(kubectl get storageclass "$sc" \
        -o jsonpath='{.metadata.annotations.storageclass\.kubernetes\.io/is-default-class}' \
        2>/dev/null || true)
    if [ "$IS_DEFAULT" = "true" ]; then
        kubectl annotate storageclass "$sc" \
            storageclass.kubernetes.io/is-default-class- \
            --overwrite
        echo "  Removed default annotation from: $sc"
    fi
done
echo "  Done."

echo ""
kubectl get storageclass 2>/dev/null || echo "  No StorageClasses found."
echo ""
echo "✅ Practice scenario is ready!"
echo "   Go create the StorageClass! 💪"
echo ""
```

# ✅ Solution

<details>
<summary>Click to expand the solution</summary>

### Step 1: Create the StorageClass manifest

```bash
vim storageclass-local-fast-path.yaml
```

```yaml
apiVersion: storage.k8s.io/v1
kind: StorageClass
metadata:
  name: local-fast-path
  annotations:
    storageclass.kubernetes.io/is-default-class: "true"
provisioner: rancher.io/local-path
volumeBindingMode: WaitForFirstConsumer
```

---

### Step 2: Apply the manifest

```bash
kubectl apply -f storageclass-local-fast-path.yaml
```

---

### Step 3: Verify the StorageClass

```bash
kubectl get storageclass
```

Expected output:

```
NAME                        PROVISIONER             RECLAIMPOLICY   VOLUMEBINDINGMODE      ALLOWVOLUMEEXPANSION
local-fast-path (default)   rancher.io/local-path   Delete          WaitForFirstConsumer   false
```

Confirm the `(default)` tag is present next to `local-fast-path`.

---

### Step 4: Verify the default annotation

```bash
kubectl describe storageclass local-fast-path
```

Look for:

```
Annotations: storageclass.kubernetes.io/is-default-class=true
```

### 🧹 Script : reset_q16_storageclass.sh

```bash
#!/bin/bash
# ============================================================
# CKA Practice | Q16: StorageClass Configuration
# reset_q16_storageclass.sh
# Removes candidate StorageClass, YAML files and restores
# default annotation to pre-existing StorageClass if present
# Run on: controlplane node
# ============================================================

set -euo pipefail

STORAGECLASS="local-fast-path"

echo ""
echo "==========================================="
echo " CKA Q16 — Restoring cluster to baseline..."
echo "==========================================="
echo ""

# ── Delete candidate StorageClass ────────────────────────────
echo "[1/3] Deleting StorageClass '$STORAGECLASS'..."
kubectl delete storageclass "$STORAGECLASS" --ignore-not-found
echo "  StorageClass deleted."

# ── Restore default annotation to pre-existing SC ────────────
echo "[2/3] Restoring default annotation to pre-existing StorageClass..."

# Find any SC other than the one candidate created
OTHER_SC=$(kubectl get storageclass \
    -o jsonpath='{.items[*].metadata.name}' 2>/dev/null | \
    tr ' ' '\n' | grep -v "^${STORAGECLASS}$" | head -1 || true)

if [ -n "$OTHER_SC" ]; then
    kubectl annotate storageclass "$OTHER_SC" \
        storageclass.kubernetes.io/is-default-class=true \
        --overwrite
    echo "  Restored default annotation to: $OTHER_SC"
else
    echo "  No pre-existing StorageClass found — skipping."
fi

# ── Delete candidate YAML files ───────────────────────────────
echo "[3/3] Removing candidate YAML files..."
rm -f "$HOME/storageclass-local-fast-path.yaml"
echo "  Candidate files removed."

echo ""
kubectl get storageclass
echo ""
echo "✅ Cluster is back to baseline!"
echo "   Safe to move to next problem. 🚀"
echo ""
```
