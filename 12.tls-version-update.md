# 🧩 Problem Statement (Configure NGINX ConfigMap for TLSv1.3 Only)

<details>
<summary>Click to expand the problem statement</summary>

A Kubernetes cluster has an NGINX Deployment running and configured via a ConfigMap. Your task is to update the ConfigMap to restrict TLS connections to TLSv1.3 only.

Your task is to:

1. Connect to the **correct host**
2. Update the **`nginx-server-config`** ConfigMap to allow only **TLSv1.3** connections
3. Restart the Deployment to apply the new configuration
4. Verify the change is working correctly

```
[candidate@base]$ ssh <hostname>
```

### 📋 Configure the following:

An NGINX Deployment named **`nginx-server`** is running in the **`nginx-static`** namespace. It is configured via a ConfigMap named **`nginx-server-config`**.

Update the **`nginx-server-config`** ConfigMap to allow **only TLSv1.3** connections.
* You may recreate, restart, or scale resources as needed
* Test the change using:

```bash
curl -k --tls-max 1.2 https://web.k8snginx.local:32000
```

> The curl command forces a maximum of TLSv1.2 — if TLSv1.3 only is correctly configured, this command should **fail**, confirming TLSv1.2 is rejected.

### 📥 Script : setup_q12_tls.sh

```bash
#!/bin/bash
# ============================================================
# CKA Practice | Q12: Configure NGINX ConfigMap for TLSv1.3
# setup_q12_tls.sh
# Creates namespace, TLS cert, ConfigMap with TLSv1.2+v1.3,
# Deployment and Service
# Re-run safe: only resets candidate work on subsequent runs
# Run on: controlplane node
# ============================================================

set -euo pipefail

NAMESPACE="nginx-static"
DEPLOYMENT="nginx-server"
CONFIGMAP="nginx-server-config"
HOSTNAME="web.k8snginx.local"
TLS_DIR="$HOME/tls-webstatic"
NODEPORT=32000

NGINX_CONF="events {}
http {
    server {
        listen 443 ssl;
        server_name $HOSTNAME;

        ssl_certificate     /etc/nginx/tls/tls.crt;
        ssl_certificate_key /etc/nginx/tls/tls.key;
        ssl_protocols       TLSv1.2 TLSv1.3;

        location / {
            return 200 'Welcome to nginx-server!';
            add_header Content-Type text/plain;
        }
    }
}"

echo ""
echo "==========================================="
echo " CKA Q12 — Setting up TLS ConfigMap scenario..."
echo "==========================================="
echo ""

# ── Step 1: Reset candidate work ─────────────────────────────
echo "[1/6] Resetting candidate work from previous attempt..."

if kubectl get configmap "$CONFIGMAP" -n "$NAMESPACE" &>/dev/null; then
    # Check if candidate already changed ssl_protocols to TLSv1.3 only
    CURRENT_PROTO=$(kubectl get configmap "$CONFIGMAP" -n "$NAMESPACE" \
        -o jsonpath='{.data.nginx\.conf}' 2>/dev/null | \
        grep ssl_protocols || true)

    if echo "$CURRENT_PROTO" | grep -q "TLSv1.3" && \
       ! echo "$CURRENT_PROTO" | grep -q "TLSv1.2"; then
        echo "  Candidate change detected — restoring ConfigMap to TLSv1.2 + TLSv1.3..."
        kubectl create configmap "$CONFIGMAP" \
            -n "$NAMESPACE" \
            --from-literal=nginx.conf="$NGINX_CONF" \
            --dry-run=client -o yaml | kubectl apply -f -
        echo "  ConfigMap restored."

        # Restart deployment only if it exists
        if kubectl get deployment "$DEPLOYMENT" -n "$NAMESPACE" &>/dev/null; then
            kubectl rollout restart deployment/"$DEPLOYMENT" -n "$NAMESPACE"
            kubectl rollout status deployment/"$DEPLOYMENT" \
                -n "$NAMESPACE" --timeout=60s
            echo "  Deployment restarted."
        fi
    else
        echo "  No candidate changes detected on ConfigMap — skipping restore."
    fi
else
    echo "  ConfigMap not found — will create fresh."
fi

echo "  Candidate work cleared."

# ── Step 2: Create namespace if not present ───────────────────
echo "[2/6] Checking namespace '$NAMESPACE'..."
if kubectl get namespace "$NAMESPACE" &>/dev/null; then
    echo "  Namespace already exists — skipping."
else
    kubectl create namespace "$NAMESPACE"
    echo "  Namespace created."
fi

# ── Step 3: Generate TLS cert and secret if not present ───────
echo "[3/6] Checking TLS secret..."
if kubectl get secret nginx-server-tls -n "$NAMESPACE" &>/dev/null; then
    echo "  TLS secret already exists — skipping."
else
    echo "  Generating TLS certificate and creating secret..."
    mkdir -p "$TLS_DIR"
    openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
        -keyout "$TLS_DIR/tls.key" \
        -out "$TLS_DIR/tls.crt" \
        -subj "/CN=$HOSTNAME" 2>/dev/null

    kubectl create secret tls nginx-server-tls \
        --cert="$TLS_DIR/tls.crt" \
        --key="$TLS_DIR/tls.key" \
        -n "$NAMESPACE"
    echo "  TLS secret created."
fi

# ── Step 4: Create ConfigMap if not present ───────────────────
echo "[4/6] Checking ConfigMap '$CONFIGMAP'..."
if kubectl get configmap "$CONFIGMAP" -n "$NAMESPACE" &>/dev/null; then
    echo "  ConfigMap already exists — skipping."
else
    echo "  Creating ConfigMap '$CONFIGMAP'..."
    kubectl create configmap "$CONFIGMAP" \
        -n "$NAMESPACE" \
        --from-literal=nginx.conf="$NGINX_CONF"
    echo "  ConfigMap created with TLSv1.2 + TLSv1.3."
fi

# ── Step 5: Create Deployment and Service if not present ──────
echo "[5/6] Checking Deployment '$DEPLOYMENT'..."
if kubectl get deployment "$DEPLOYMENT" -n "$NAMESPACE" &>/dev/null; then
    echo "  Deployment already exists — skipping."
else
    echo "  Creating Deployment and Service..."
    kubectl apply -f - <<EOF
apiVersion: apps/v1
kind: Deployment
metadata:
  name: $DEPLOYMENT
  namespace: $NAMESPACE
spec:
  replicas: 1
  selector:
    matchLabels:
      app: $DEPLOYMENT
  template:
    metadata:
      labels:
        app: $DEPLOYMENT
    spec:
      containers:
      - name: nginx
        image: nginx:1.27
        ports:
        - containerPort: 443
        volumeMounts:
        - name: nginx-config
          mountPath: /etc/nginx/nginx.conf
          subPath: nginx.conf
        - name: tls-secret
          mountPath: /etc/nginx/tls
          readOnly: true
      volumes:
      - name: nginx-config
        configMap:
          name: $CONFIGMAP
      - name: tls-secret
        secret:
          secretName: nginx-server-tls
---
apiVersion: v1
kind: Service
metadata:
  name: $DEPLOYMENT-svc
  namespace: $NAMESPACE
spec:
  type: NodePort
  selector:
    app: $DEPLOYMENT
  ports:
  - port: 443
    targetPort: 443
    nodePort: $NODEPORT
    protocol: TCP
EOF

    echo "  Waiting for Deployment to be Ready..."
    kubectl wait --for=condition=available deployment/"$DEPLOYMENT" \
        -n "$NAMESPACE" --timeout=120s
    echo "  Deployment is Ready."
fi

# ── Step 6: Add /etc/hosts entry if not present ───────────────
echo "[6/6] Checking /etc/hosts entry..."
if grep -q "$HOSTNAME" /etc/hosts; then
    echo "  /etc/hosts entry already exists — skipping."
else
    NODE_IP=$(kubectl get nodes \
        --selector='node-role.kubernetes.io/control-plane' \
        -o jsonpath='{.items[0].status.addresses[?(@.type=="InternalIP")].address}')
    echo "$NODE_IP $HOSTNAME" | sudo tee -a /etc/hosts > /dev/null
    echo "  Added: $NODE_IP $HOSTNAME"
fi

echo ""
kubectl get configmap "$CONFIGMAP" -n "$NAMESPACE"
echo ""
kubectl get deployment "$DEPLOYMENT" -n "$NAMESPACE"
echo ""
echo "✅ Practice scenario is ready!"
echo ""
echo "   ConfigMap '$CONFIGMAP' currently allows TLSv1.2 + TLSv1.3"
echo "   Your task: update it to allow TLSv1.3 ONLY"
echo ""
echo "   Test after change:"
echo "   curl -k --tls-max 1.2 https://web.k8snginx.local:32000"
echo "   (should FAIL — confirming TLSv1.2 is rejected)"
echo ""
echo "   💪 Go update the ConfigMap!"
echo ""
```

# ✅ Solution

<details>
<summary>Click to expand the solution</summary>

### Step 1: Inspect the current ConfigMap

```bash
kubectl describe configmap nginx-server-config -n nginx-static
```

Note the current `ssl_protocols` line — it currently allows both `TLSv1.2 TLSv1.3`.

---

### Step 2: Edit the ConfigMap

```bash
kubectl edit configmap nginx-server-config -n nginx-static
```

Locate the `ssl_protocols` line and change it from:

```nginx
ssl_protocols       TLSv1.2 TLSv1.3;
```

To:

```nginx
ssl_protocols       TLSv1.3;
```

Save and exit.

---

### Step 3: Restart the Deployment to apply the new ConfigMap

```bash
kubectl rollout restart deployment/nginx-server -n nginx-static
```

Wait for rollout to complete:

```bash
kubectl rollout status deployment/nginx-server -n nginx-static
```

---

### Step 4: Verify the pod is running

```bash
kubectl get pods -n nginx-static
```

Expected output:

```
NAME                          READY   STATUS    RESTARTS   AGE
nginx-server-xxxxxxxxx-xxxxx    1/1     Running   0          10s
```

---

### Step 5: Test the configuration

Run the test command — with `--tls-max 1.2` forcing TLSv1.2:

```bash
curl -k --tls-max 1.2 https://web.k8snginx.local:32000
```

Expected output — connection **fails**:

```
curl: (35) error:0A00042E:SSL routines::tlsv1 alert protocol version
```

This confirms TLSv1.2 is **rejected** — only TLSv1.3 is accepted. ✅

---

### Step 6: Confirm TLSv1.3 still works

```bash
curl -k --tlsv1.3 https://web.k8snginx.local:32000
```

Expected output:

```
Welcome to nginx-server!
```

TLSv1.3 connections succeed. ✅

</details>
