# 🧩 Problem Statement (Argo CD Installation via Helm)

<details>
<summary>Click to expand the problem statement</summary>

A Kubernetes cluster requires Argo CD to be installed as the GitOps continuous delivery tool using Helm.

Your task is to:

1. Connect to the **correct host**
2. Add the **official Argo Helm repository**
3. Generate a **Helm template file** with CRDs disabled
4. Install **Argo CD** using the Helm chart

```
[candidate@base]$ ssh <hostname>
```

### 📋 Configure the following:

1. Add the official Argo Helm repository named **`argo`**
2. Use Argo CD chart version **`5.5.22`**
3. Generate a Helm template file named **`~/argo-helm.yaml`** with `crds.install=false`
4. Install Argo CD using the Helm chart ensuring **CRDs are not reinstalled**

</details>

# 🛠 Setup Practice Scenario

<details>
<summary>Click to expand setup steps</summary>

| Script | Purpose |
|--------|---------|
| `setup_q03_argocd.sh` | Cleans any previous ArgoCD state and ensures Helm is available — run before practice (re-run anytime) |

---

### 📥 Script : setup_q03_argocd.sh

```bash
#!/bin/bash
# ============================================================
# CKA Practice | Q03: Argo CD Installation via Helm
# setup_q03_argocd.sh
# Pre-installs ArgoCD CRDs, ensures Helm available
# Re-run safe: only resets candidate work on subsequent runs
# Run on: controlplane node
# ============================================================

set -euo pipefail

NAMESPACE="argocd"
HELM_RELEASE="argocd"
REPO_NAME="argo"
TEMPLATE_FILE="$HOME/argo-helm.yaml"
CHART_VERSION="5.5.22"

echo ""
echo "==========================================="
echo " CKA Q03 — Setting up ArgoCD scenario..."
echo "==========================================="
echo ""

# ── Step 1: Reset candidate work ─────────────────────────────
echo "[1/4] Resetting candidate work from previous attempt..."

# Uninstall candidate helm release
helm uninstall "$HELM_RELEASE" -n "$NAMESPACE" 2>/dev/null || true

# Remove candidate helm repo
helm repo remove "$REPO_NAME" 2>/dev/null || true

# Remove candidate template file
rm -f "$TEMPLATE_FILE"

echo "  Candidate work cleared."

# ── Step 2: Verify Helm is installed ─────────────────────────
echo "[2/4] Checking Helm..."
if ! command -v helm &>/dev/null; then
    echo "  Helm not found — installing..."
    curl -fsSL https://raw.githubusercontent.com/helm/helm/main/scripts/get-helm-3 | bash
    echo "  Helm installed."
else
    echo "  Helm already installed: $(helm version --short)"
fi

# ── Step 3: Create argocd namespace if not present ────────────
echo "[3/4] Checking namespace '$NAMESPACE'..."
if kubectl get namespace "$NAMESPACE" &>/dev/null; then
    echo "  Namespace already exists — skipping."
else
    kubectl create namespace "$NAMESPACE"
    echo "  Namespace created."
fi

# ── Step 4: Pre-install ArgoCD CRDs if not present ───────────
echo "[4/4] Checking ArgoCD CRDs..."
if kubectl get crd applications.argoproj.io &>/dev/null; then
    echo "  ArgoCD CRDs already installed — skipping."
else
    echo "  Pre-installing ArgoCD CRDs only..."

    # Install ONLY CRDs from upstream — not ClusterRoles or other resources
    # This avoids helm ownership conflicts when candidate runs helm install
    kubectl apply -k "https://github.com/argoproj/argo-cd/manifests/crds?ref=v2.5.0"

    echo "  ArgoCD CRDs installed."

    # Verify CRDs are present
    kubectl get crds | grep argoproj
fi

echo ""
echo "✅ Practice scenario is ready!"
echo "   ArgoCD CRDs are already installed in the cluster."
echo "   Go install Argo CD via Helm with crds.install=false! 💪"
echo ""
```

# ✅ Solution

<details>
<summary>Click to expand the solution</summary>

### Step 1: Add the official Argo Helm repository

```bash
helm repo add argo https://argoproj.github.io/argo-helm
```

Update the repo to fetch latest chart metadata:

```bash
helm repo update
```

Verify the repo was added:

```bash
helm repo list
```

Expected output:

```
NAME    URL
argo    https://argoproj.github.io/argo-helm
```

---

### Step 2: Verify the chart version is available

```bash
helm search repo argo/argo-cd --versions | grep 5.5.22
```

Expected output:

```
argo/argo-cd    5.5.22    ...
```

---

### Step 3: Generate the Helm template file

```bash
helm template argocd argo/argo-cd \
  --namespace argocd \
  --version 5.5.22 \
  --set crds.install=false \
  > ~/argo-helm.yaml
```

Verify the file was generated:

```bash
ls -lh ~/argo-helm.yaml
```

---

### Step 4: Install Argo CD using the Helm chart

```bash
helm install argocd argo/argo-cd \
  --namespace argocd \
  --version 5.5.22 \
  --set crds.install=false
```

---

### Step 5: Verify the installation

```bash
helm list -n argocd
```

Expected output:

```
NAME      NAMESPACE   REVISION   STATUS     CHART           APP VERSION
argocd    argocd      1          deployed   argo-cd-5.5.22  ...
```

Check all pods are running:

```bash
kubectl get pods -n argocd
```

All pods should show `Running` status.

# ↩️ Restore Cluster State

<details>
<summary>Click to expand reset steps</summary>

| Script | Purpose |
|--------|---------|
| `reset_q03_argocd.sh` | Uninstalls ArgoCD, removes namespace, helm repo and template file — run before moving to next problem |

---

### 🧹 Script : reset_q03_argocd.sh

```bash
#!/bin/bash
# ============================================================
# CKA Practice | Q03: Argo CD Installation via Helm
# reset_q03_argocd.sh
# Uninstalls ArgoCD helm release, removes namespace,
# ArgoCD CRDs, helm repo and template file
# Run on: controlplane node
# ============================================================

set -euo pipefail

NAMESPACE="argocd"
HELM_RELEASE="argocd"
REPO_NAME="argo"
TEMPLATE_FILE="$HOME/argo-helm.yaml"
CHART_VERSION="5.5.22"

echo ""
echo "==========================================="
echo " CKA Q03 — Restoring cluster to baseline..."
echo "==========================================="
echo ""

# ── Uninstall Helm release ────────────────────────────────────
echo "[1/5] Uninstalling Helm release '$HELM_RELEASE'..."
helm uninstall "$HELM_RELEASE" -n "$NAMESPACE" 2>/dev/null || true
echo "  Helm release removed."

# ── Delete namespace ──────────────────────────────────────────
echo "[2/5] Deleting namespace '$NAMESPACE'..."
kubectl delete namespace "$NAMESPACE" --ignore-not-found
echo "  Namespace and all resources removed."

# ── Remove ArgoCD CRDs ────────────────────────────────────────
echo "[3/5] Removing ArgoCD CRDs..."
kubectl get crds | grep argoproj | awk '{print $1}' | \
    xargs -r kubectl delete crd --ignore-not-found
echo "  ArgoCD CRDs removed."

# ── Remove Helm repo ──────────────────────────────────────────
echo "[4/5] Removing Helm repo '$REPO_NAME'..."
helm repo remove "$REPO_NAME" 2>/dev/null || true
echo "  Helm repo removed."

# ── Remove template file ──────────────────────────────────────
echo "[5/5] Removing template file and candidate files..."
rm -f "$TEMPLATE_FILE"
echo "  Template file removed."

echo ""
echo "✅ Cluster is back to baseline!"
echo "   Safe to move to next problem. 🚀"
echo ""
```
