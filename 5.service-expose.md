# 🧩 Problem Statement (Service Exposure — NodePort Type)

<details>
<summary>Click to expand the problem statement</summary>

A Kubernetes cluster has an existing Deployment that needs its container port exposed and made accessible outside the cluster via a NodePort Service.

Your task is to:

1. Connect to the **correct host**
2. Update the existing Deployment to **expose the container port**
3. Create a **NodePort Service** to expose the Deployment externally

```
[candidate@base]$ ssh <hostname>
```


### 📋 Configure the following:

In the **`web-frontend`** namespace:

1. Update the **`nginx-app`** Deployment to expose port **`80/tcp`** (container port) for the nginx container
2. Create a **NodePort** type Service named **`nginx-app-svc`** to expose the Deployment on port **`80/tcp`** (service port mapping to the container port)

</details>

### 📥 Script : setup_q05_nodeport.sh

```bash
#!/bin/bash
# ============================================================
# CKA Practice | Q05: Service Exposure (NodePort Type)
# setup_q05_nodeport.sh
# Creates namespace and nginx-app deployment without container port
# Re-run safe: only resets candidate work on subsequent runs
# Run on: controlplane node
# ============================================================

set -euo pipefail

NAMESPACE="web-frontend"
DEPLOYMENT="nginx-app"
SERVICE="nginx-app-svc"

echo ""
echo "==========================================="
echo " CKA Q05 — Setting up NodePort scenario..."
echo "==========================================="
echo ""

# ── Step 1: Reset candidate work ─────────────────────────────
echo "[1/2] Resetting candidate work from previous attempt..."

# Delete candidate-created service
kubectl delete svc "$SERVICE" -n "$NAMESPACE" --ignore-not-found

# Delete candidate YAML file
rm -f "$HOME/nginx-app-svc.yaml"

# Check if candidate added ports to deployment
PORT_COUNT=$(kubectl get deployment "$DEPLOYMENT" -n "$NAMESPACE" \
    -o jsonpath='{.spec.template.spec.containers[0].ports}' 2>/dev/null | \
    python3 -c "import sys,json; d=sys.stdin.read().strip(); print(len(json.loads(d)) if d and d!='null' else 0)" \
    2>/dev/null || echo "0")

if [ "$PORT_COUNT" -gt 0 ]; then
    echo "  Ports detected on deployment — restoring to original state..."
    kubectl replace --force -f - <<EOF
apiVersion: apps/v1
kind: Deployment
metadata:
  name: $DEPLOYMENT
  namespace: $NAMESPACE
spec:
  replicas: 1
  selector:
    matchLabels:
      app: nginx-app
  template:
    metadata:
      labels:
        app: nginx-app
    spec:
      containers:
      - name: nginx
        image: nginx:latest
EOF
else
    echo "  No candidate changes detected on deployment — skipping restore."
fi

echo "  Candidate work cleared."

# ── Step 2: Create namespace and deployment if not present ────
echo "[2/2] Checking namespace and deployment..."

if ! kubectl get namespace "$NAMESPACE" &>/dev/null; then
    kubectl create namespace "$NAMESPACE"
    echo "  Namespace created."
else
    echo "  Namespace already exists — skipping."
fi

if ! kubectl get deployment "$DEPLOYMENT" -n "$NAMESPACE" &>/dev/null; then
    echo "  Creating deployment '$DEPLOYMENT'..."
    kubectl apply -f - <<EOF
apiVersion: apps/v1
kind: Deployment
metadata:
  name: $DEPLOYMENT
  namespace: $NAMESPACE
spec:
  replicas: 1
  selector:
    matchLabels:
      app: nginx-app
  template:
    metadata:
      labels:
        app: nginx-app
    spec:
      containers:
      - name: nginx
        image: nginx:latest
EOF
else
    echo "  Deployment already exists — skipping."
fi

# ── Wait for pod to be ready ──────────────────────────────────
echo "  Waiting for pod to be Running..."
kubectl wait --for=condition=available deployment/"$DEPLOYMENT" \
    -n "$NAMESPACE" --timeout=120s
echo "  nginx-app is Ready."

echo ""
kubectl get deployment "$DEPLOYMENT" -n "$NAMESPACE"
echo ""
echo "✅ Practice scenario is ready!"
echo "   Go expose the container port and create the Service! 💪"
echo ""
```

</details>

# ✅ Solution

<details>
<summary>Click to expand the solution</summary>

### Step 1: Update the Deployment to expose container port 80

```bash
kubectl edit deployment nginx-app -n web-frontend
```

Locate the `containers` section and add the `ports` block:

```yaml
containers:
- name: nginx
  image: nginx:latest
  ports:                  # Add this block
  - containerPort: 80
    protocol: TCP
```

Save and exit.

---

### Step 2: Verify the Deployment rollout

```bash
kubectl rollout status deployment/nginx-app -n web-frontend
```

---

### Step 3: Create the NodePort Service

#### Option 1 — Using kubectl expose (Quick)

```bash
kubectl expose deployment nginx-app \
  --name=nginx-app-svc \
  --type=NodePort \
  --port=80 \
  --target-port=80 \
  -n web-frontend
```

#### Option 2 — Using YAML manifest

```bash
vim nginx-app-svc.yaml
```

```yaml
apiVersion: v1
kind: Service
metadata:
  name: nginx-app-svc
  namespace: web-frontend
spec:
  type: NodePort
  selector:
    app: nginx-app
  ports:
  - port: 80
    targetPort: 80
    protocol: TCP
```

---

### Step 4: Apply the Service

```bash
kubectl apply -f nginx-app-svc.yaml
```

---

### Step 5: Verify the Service

```bash
kubectl get svc nginx-app-svc -n web-frontend
```

Expected output:

```
NAME            TYPE       CLUSTER-IP      EXTERNAL-IP   PORT(S)        AGE
nginx-app-svc   NodePort   10.96.x.x       <none>        80:3xxxx/TCP   10s
```

---

### Step 6: Test the Service

Get the Node IP and NodePort:

```bash
kubectl get nodes -o wide
kubectl get svc nginx-app-svc -n web-frontend
```

```bash
curl http://<NODE-IP>:<NODE-PORT>
```

You should receive the default nginx welcome page.
