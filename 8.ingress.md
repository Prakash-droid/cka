# 🧩 Problem Statement (Ingress Configuration)

<details>
<summary>Click to expand the problem statement</summary>

A Kubernetes cluster has an existing service that needs to be exposed via an Ingress resource for HTTP path-based routing.

Your task is to:

1. Connect to the **correct host**
2. Create an **Ingress resource** in the correct namespace
3. Configure routing rules so the service is reachable via the specified URL

```
[candidate@base]$ ssh <hostname>
```

### 📋 Configure the following:

* Create an Ingress named **`echoserver-ingress`** in the **`sound-repeater`** namespace
* Route all requests to **`http://example.org/echo`** → **`echoserver-service`** on port **`8080`**
* Use ingress class **`nginx`**

Once created, verify the service is reachable using:

```bash
curl http://example.org:32000/echo
```

### 📥 Script : setup_q08_ingress.sh

```bash
#!/bin/bash
# ============================================================
# CKA Practice | Q08: Ingress Configuration
# setup_q08_ingress.sh
# Installs ingress-nginx, creates namespace, deployment,
# service and /etc/hosts entry for practice
# Re-run safe: only resets candidate work on subsequent runs
# Run on: controlplane node
# ============================================================

set -euo pipefail

NAMESPACE="sound-repeater"
DEPLOYMENT="echoserver"
SERVICE="echoserver-service"
HOSTNAME="example.org"

echo ""
echo "==========================================="
echo " CKA Q08 — Setting up Ingress scenario..."
echo "==========================================="
echo ""

# ── Step 1: Reset candidate work ─────────────────────────────
echo "[1/6] Resetting candidate work from previous attempt..."
kubectl delete ingress echoserver-ingress -n "$NAMESPACE" --ignore-not-found
rm -f "$HOME/ingress-echoserver.yaml"
echo "  Candidate work cleared."

# ── Step 2: Install ingress-nginx if not present ──────────────
echo "[2/6] Checking ingress-nginx..."
if kubectl get namespace ingress-nginx &>/dev/null && \
   kubectl get pods -n ingress-nginx \
       -l app.kubernetes.io/component=controller \
       --no-headers 2>/dev/null | grep -q Running; then
    echo "  ingress-nginx already running — skipping."
else
    echo "  Installing ingress-nginx..."
    kubectl apply -f https://raw.githubusercontent.com/kubernetes/ingress-nginx/controller-v1.11.0/deploy/static/provider/cloud/deploy.yaml

    echo "  Patching ingress-nginx service to NodePort..."
    kubectl patch svc ingress-nginx-controller \
        -n ingress-nginx \
        -p '{"spec": {"type": "NodePort"}}'

    echo "  Setting nodePort 32000 for HTTP..."
    kubectl patch svc ingress-nginx-controller \
        -n ingress-nginx \
        -p '{"spec": {"ports": [{"port": 80, "targetPort": 80, "nodePort": 32000, "protocol": "TCP", "name": "http"}]}}'

    echo "  Waiting for ingress-nginx controller to be Ready..."
    kubectl wait --for=condition=ready pod \
        -l app.kubernetes.io/component=controller \
        -n ingress-nginx --timeout=180s
    echo "  ingress-nginx installed and ready."
fi


# ── Step 3: Add /etc/hosts entry if not present ───────────────
echo "[3/6] Checking /etc/hosts entry..."
if grep -q "$HOSTNAME" /etc/hosts; then
    echo "  /etc/hosts entry already exists — skipping."
else
    NODE_IP=$(kubectl get nodes \
        --selector='node-role.kubernetes.io/control-plane' \
        -o jsonpath='{.items[0].status.addresses[?(@.type=="InternalIP")].address}')
    echo "$NODE_IP $HOSTNAME" | sudo tee -a /etc/hosts > /dev/null
    echo "  Added: $NODE_IP $HOSTNAME"
fi

# ── Step 4: Create namespace if not present ───────────────────
echo "[4/6] Checking namespace '$NAMESPACE'..."
if kubectl get namespace "$NAMESPACE" &>/dev/null; then
    echo "  Namespace already exists — skipping."
else
    kubectl create namespace "$NAMESPACE"
    echo "  Namespace created."
fi

# ── Step 5: Create deployment and service if not present ──────
echo "[5/6] Checking deployment '$DEPLOYMENT'..."
if kubectl get deployment "$DEPLOYMENT" -n "$NAMESPACE" &>/dev/null; then
    echo "  Deployment already exists — skipping."
else
    echo "  Creating deployment and service..."
    kubectl apply -f - <<EOF
apiVersion: apps/v1
kind: Deployment
metadata:
  name: $DEPLOYMENT
  namespace: $NAMESPACE
spec:
  replicas: 1
  selector:
    matchLabels:
      app: echoserver
  template:
    metadata:
      labels:
        app: echoserver
    spec:
      containers:
      - name: echoserver
        image: gcr.io/google_containers/echoserver:1.10
        ports:
        - containerPort: 8080
---
apiVersion: v1
kind: Service
metadata:
  name: $SERVICE
  namespace: $NAMESPACE
spec:
  selector:
    app: echoserver
  ports:
  - name: http
    port: 8080
    targetPort: 8080
EOF
fi

# ── Step 6: Wait for pod to be ready ─────────────────────────
echo "[6/6] Waiting for pod to be Running..."
kubectl wait --for=condition=available deployment/"$DEPLOYMENT" \
    -n "$NAMESPACE" --timeout=120s
echo "  echoserver is Ready."

echo ""
kubectl get deployment "$DEPLOYMENT" -n "$NAMESPACE"
echo ""
echo "✅ Practice scenario is ready!"
echo "   Go create the Ingress! 💪"
echo ""
```

# ✅ Solution

<details>
<summary>Click to expand the solution</summary>

### Step 1: Verify the service exists

```bash
kubectl get svc echoserver-service -n sound-repeater
```

Confirm the service is present and running on port `8080` before creating the Ingress.

---

### Step 2: Create the Ingress manifest

```bash
vim ingress-echoserver.yaml
```

```yaml
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: echoserver-ingress
  namespace: sound-repeater
  annotations:
    nginx.ingress.kubernetes.io/rewrite-target: /
spec:
  ingressClassName: nginx
  rules:
  - host: example.org
    http:
      paths:
      - path: /echo
        pathType: Prefix
        backend:
          service:
            name: echoserver-service
            port:
              number: 8080
```

---

### Step 3: Apply the manifest

```bash
kubectl apply -f ingress-echoserver.yaml
```

---

### Step 4: Verify the Ingress

```bash
kubectl get ingress echoserver-ingress -n sound-repeater
```

Expected output:

```
NAME                  CLASS   HOSTS         ADDRESS        PORTS   AGE
echoserver-ingress    nginx   example.org   <ingress-ip>   80      10s
```

---

### Step 5: Test the route

```bash
curl http://example.org:32000/echo
```

You should receive an echo response confirming routing is working correctly.

</details>
